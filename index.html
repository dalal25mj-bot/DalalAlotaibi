The Core Idea of Physics

Quick access: UK resources
National CurriculumBBC BitesizeIsaac PhysicsInst. of PhysicsPhETAll resources & books →

Physics describes nature with simple models, tests them with measurement, and uses them to predict. When prediction and data disagree, the model is refined. Every UK physics course, from KS3 to A-Level, trains this one loop.

Final Project: The Learning Machine

“SMART-LAUNCH”: a sensor-driven launcher that learns

Students build a low-power spring/coil launcher with sensors and a micro-controller. It collects its own launch data, trains a model to predict landing distance, and is tested against physics theory. Each curriculum strand becomes a machine module, so completing it shows full coverage.

Machine Learning Lab

Physics predicts range as R = (v²/g)·sin 2θ. The machine does not know this: it fits R = w·sin 2θ from data using gradient descent. Does it find w = v²/g?

Collect data first.

Try more noise, then more data points. Larger datasets reduce the effect of random error, as repeated measurements do in the lab.

Concept map: physics → ML
Linear fit straight-line graphs (GCSE/A-Level)
Gradient descent following a slope to a minimum
Neural network weighted sums, like resistor networks
Overfitting a curve through every error bar
Classification decay type from cloud-chamber tracks

Planned changes

A digital, machine-readable national curriculum; less crowded content; science re-sequenced and refined from KS1 to KS4; GCSE exam volume reduced by about 10%; EBacc measure removed and Progress 8 reformed; oracy frameworks; a new Year 8 reading test; enrichment benchmarks.

Triple science

The review recommends a national entitlement to separate sciences at GCSE, so physics should be taught as a strong standalone route.
